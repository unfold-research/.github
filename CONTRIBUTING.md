# Contributing to Unfold's open projects

Thank you for looking. Each repository has its own guide; start there:

- [bioswarm](https://github.com/unfold-research/bioswarm/blob/main/CONTRIBUTING.md): the research, protocol, SDK and
  benchmark harness. Research questions, replications and natural mechanisms are as welcome as code.
- [bioswarm-plugin](https://github.com/unfold-research/bioswarm-plugin): the plugin that runs inside agent hosts.

Everywhere:

- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).
- Report vulnerabilities privately ([SECURITY](SECURITY.md)).
- Never include secrets, spending figures or personal data in issues, pull requests or commits.
- Keep claims at the strength of their evidence: no result is upgraded in a README, an issue or a pull request.
- Code is Apache-2.0; research content is CC BY 4.0. By contributing you agree to license your contribution the same way.
